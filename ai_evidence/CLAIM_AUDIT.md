# 인수한 AI 주장 대조의 재현

인수한 원출력8건의 선정 주장23개를 독립 Decimal 계산·기존 CSV·원입력 및 공식 자료와 대조했다. 이 기록은 연구 저장소의 코드 검증 자료다. 공모전 참가작 원고, 사람의 금융판정 또는 제출 승인 기록이 아니다.

```sh
python scripts/audit_ai_claims.py --check
```

Python 3.10 이상과 표준 라이브러리만 사용한다. 외부 AI·네트워크·비공개 작업 폴더·참조 금융모형 import 없이 실행된다. [검산 JSON](claim_audit.json)은 결정적으로 재생성된다. 검토 후 갱신할 때는 `--write`를 사용한다.

## 검토와 자동 계산의 경계

| 자료 | 역할 |
|---|---|
| [원출력](../apps/demo/ai/evaluations/cpa_experiment_runs.json) | 수정하지 않는 제공 기록. SHA-256 고정 |
| [검토 주석](claim_review_notes.json) | Codex가 작성한 문맥·공식 자료 해석 및 계산 기준. 코드 실행으로 법령을 새로 조회하는 것은 아님 |
| [검산 코드](../scripts/audit_ai_claims.py) | 월별 현금, 원출력 자체 산식, 포함 월 수, 주장 ID와 동일 입력 CSV 대조 |
| [검산 결과](claim_audit.json) | 각 원문 JSON 위치, 근거·한계, 계산값과 미확인 상태. 사람 승인 필드 미완료 유지 |

원출력 해시가 달라지면 검산은 중단된다. 원출력의 내용 변경 후에도 기존 검토를 자동 승계하지 않는다. 검토 주석은 해당 해시의 문맥을 읽고 작성했으며, 프로그램이 모든 자연어 주장의 참·거짓을 스스로 판정한다는 뜻이 아니다. 원출력 파일의 상태 `IMPORTED_UNREVIEWED`는 제공자 호출의 독립 증명·사람 최종 판정이 남아 있다는 뜻으로 유지한다.

## 확인한 차이

| 대상 | 확인 결과와 한계 |
|---|---|
| 잔액 일치6건 | 동일 입력의 해당 월 금액은 일치. 권고 전체 수용이나 현실 조건 확인을 뜻하지 않음 |
| E1/c2·E6/c2 | 9월까지 현금충당이 가능하다는 제한된 사실은 맞음. 이후 소득 공백 및 장기 전략 우월성과 구분 |
| E4/c4 | 출력의 월80 근로 가정을 넣으면18개월 말125. 안전자금360을 별도 현금으로 더하지 않음 |
| E5/c1 | 출력이 추가한 지원금·근로 조건이면 최저585. 지원 자격·선정·중복수급·지급일은 미확인 |
| E6/c1 | 출력 자체 산식은960으로310과 다름 |
| E7/c2 | 월80만원 해석에서12월350. 원문의 단위 오기는 해소되지 않아 조건을 명시 |
| E8/c1 | 지출합1355·9월잔액405로1295·465와 다름 |
| E8/c2 | 표 항목합14725 자체는 일치. 근거 없는 투자수익·임금 및61개월 기간은 별도 문제 |
| 선정 주장 밖 E3 문장 | 140×7은980이며1000 표기는 오기. 같은 출력의 총지출·잔액은 맞음. 선정23개 집계에 추가하지 않음 |

원 프롬프트는 2027년6월 이후 수험비5만원이 계속된다. 반면 Python v4 A/U의 이후 비용 일정은 다르다. 따라서 **동일 입력인 2027년9월까지10개월만** CSV와 비교한다. 원입력을 무소득18개월로 계산한 기말−595를 v4 A/U−555와 비교하여 오류라고 부르지 않는다. 첫 고정하한360 위반은10월, 첫 음수 잔액은 다음 해1월이다. 월중 입출금 순서는 검증하지 않는다.

## 공식 자료의 범위

자료 검토일은2026-11-13이다. [금융위원회 결과 발표](https://fsc.go.kr/no010101/87628)는 집단 통계와 부분합격 다음 회 적용의 근거이며 개인 확률의 근거는 아니다. [수습 안정화 발표](https://www.fsc.go.kr/no010101/87013)는 장기 미지정 신청자 중심의 한시적 방안으로, 전원 즉시 고용·급여를 보장하지 않는다.

[국세청 안내](https://www.nts.go.kr/nts/na/ntt/selectNttInfo.do?mi=2201&nttSn=1350361)의2026.04.20 공식 PDF1~2쪽은2025년 귀속 소득에 대한 통지·납부·유예 신청 안내다. 이를 미래연도 상환액으로 전용하지 않는다. 시행령 조문은 앞선 열람 기록과 금융위원회 설명을 구분했다. 이번 법령 사이트 재접속은 시스템 점검 안내로 연결됐으며, 최신 조문을 새로 확인했다고 표시하지 않았다.

새 제공자 호출, 실제 지원금 수급·채용 검증, 사람의 판정·서명·공모전 접수는 수행하지 않았다. 기존 금융 수식·입력·표·그림·원출력도 변경하지 않았다.
