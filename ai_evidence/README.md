| 구분 | 상태 |

| 원출력 파일 | E1~E8 8건. systemPrompt·prompt·output·provider·model·ranAt·claims·AI 1차 의견 포함 |

## 완료 기준

실험을 완료로 올리려면 원본 실행 경위·모델·시각·입력·출력을 확인하고, 공식 근거 또는 동일 입력 독립 계산으로 판정한 후 사람이 사유·검토자·시각과 고객 권고 전후를 기록합니다. 오류가 없으면 그대로 기록합니다. 키·개인정보는 공개하지 않습니다. 과거 기록의 원출력을 현재 바이블 수치에 맞추어 수정하지 않습니다.
