# 3인·3일 실행계획의 입력 브리프

기준일: 2026-11-12 KST. 상태: 원본 소스 인수 후 갱신한 사전 입력자료. 최종 일정·개인별 프롬프트·PDF는 미제작입니다.

프로젝트는 「합격해도 끝나지 않는다」, B안 가상 고객 재무설계입니다. 마감은 2026-11-16 23:59 KST이며, 집중 작업일은 11월 13~15일로 계획했습니다. 아래는 실제 확보한 자산과 남은 검증을 구분한 계획 입력이며 공식 참가작 완성을 뜻하지 않습니다.

## 이미 있는 기능과 재개발하지 않을 범위

Rust의 고객 입력·A/B/C/D 계산·월중 최저·전환 신호·60개월 비교·스트레스·ICL 보조 계산과 React 화면을 인수했습니다. AI 상담·원출력 기록·인간 판정·브라우저 점검 기록·인쇄 보고서의 코드도 있습니다. 화면·API가 실제로 연결되는지는 실행 증거로 확인하며 소스 존재를 검증 완료와 혼동하지 않습니다.

현재 우선 작업은 신규 화면 개발이 아니라 **기존 앱의 실행·안전한 통합, 두 모형의 차이 표시, 제공된 AI 기록의 인간 검증, 필수 참가작 작성**입니다. 세부 기능과 근거는 [기능 목록](DEMO_FEATURE_INVENTORY.md)에 있습니다.

## 의존성과 품질 게이트

1. 원본 커밋 확보 → 원본 변경 범위·비밀정보·라이선스 확인 → 설치·빌드·API·주요 화면 확인 → 인수 PR과 필수 CI 통과 → 병합.
2. Python v4와 Rust의 단위·임금·시점·안전자금·할인 정의 비교 → 별도 프로필 표시 → 금융 결과를 변경할 필요가 있으면 주진호 검토와 교차 검산.
3. 수입 AI 원출력·실험 ID의 의미 매핑 → 원본 입력에 맞는 독립 판정 → 사람이 판정·수정 전후 권고 기록 → AI 기술서.
4. 필수 본문+AI 부록 → 숫자·출처·익명성·형식 QA → 팀원 서명과 제출 담당 확인.

이번 실행 검증은 API 키 없이 수행합니다. 외부 LLM을 재호출해 과금하거나 기존 기록을 새 실험으로 작성하지 않습니다. 최신 실행·빌드·통과/실패 수치는 [인수 보고](../demo/DEMO_INTAKE_REPORT.md)에만 모아 중복된 성공 주장을 피합니다.
