## 기능별 증거 양식

각 기능에 다음을 추가한다.

```text
기능 ID:
상태: VERIFIED / PARTIAL / NOT_IMPLEMENTED / DIFF_FOUND / OUT_OF_SCOPE
원본 저장소·커밋:
소스 파일·함수:
입력·단위·기준 버전:
출력의 종류: Python 계산 / 고정 예시 / 임시 프런트 계산 / 미검증 / placeholder
실행 명령·환경:
확인한 동작·결과 파일:
차이·오류·영향:
보존할 기존 동작:
담당자·검토자:
예상 난이도·선행 작업·우선순위:
완료 기준·실패 시 대체안:
```

실제 키·토큰·금융 개인정보를 증거 파일에 넣지 않는다. AI 실험 원출력을 보존할 때도 민감정보 없는 합성 입력을 사용한다. 실행에 사용한 비밀값 대신 환경변수 이름과 설정 여부만 기록한다.
