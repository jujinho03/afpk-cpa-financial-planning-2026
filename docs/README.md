# 문서 지도

이 폴더는 계산 결과를 **왜 믿을 수 있는지**와 **어디까지가 가정인지**를 설명합니다. 처음이라면 위에서부터 읽으면 됩니다.

| 순서 | 문서 | 답하는 질문 |
|---|---|---|
| 1 | [심사위원을 위한 3분 안내](JUDGES_GUIDE.md) | 결론은 무엇이고, 무엇이 바뀌면 결론이 바뀌는가 |
| 2 | [가정 원장](assumptions/BASELINE.md) | 고객·소득·지출·가중치는 어떤 값을 썼는가 |
| 3 | [알려진 모형 한계](decisions/KNOWN_LIMITATIONS.md) | 모형이 다루지 않는 것과 그 처리 방식은 무엇인가 |
| 4 | [공식 출처와 원본 해시](references/README.md) | 공식 통계·제도 근거는 어디서 왔는가 |
| 5 | [프로젝트 기획서](bible/AFPK_CPA_아이디어_기획서.md) ([PDF](bible/AFPK_CPA_아이디어_기획서.pdf)) | 문제 정의와 재무설계 6단계의 전체 설계 |

## 폴더별 역할

| 폴더 | 역할 | 상태 |
|---|---|---|
| [`bible/`](bible/) | 팀이 처음 합의한 기획서 원본 | 원본 보존(SHA-256 고정, 수정하지 않음) |
| [`assumptions/`](assumptions/) | 계산에 들어간 모든 가상 가정 | 현재 기준 |
| [`decisions/`](decisions/) | 모형 한계 원장, 공개 범위 결정 | 현재 기준 |
| [`references/`](references/) | 공식 출처 목록, 원본·데모 인수 해시 | 현재 기준 |
| [`demo/`](demo/) | 기존 웹 데모의 인수·보안·두 모형 차이 검토 | 현재 기준 |
| [`archive/`](archive/) | 지난 일정 입력자료와 저장소 초기 설정 기록 | 보관용. 현재 결론의 근거가 아님 |

공식 참가작(재무설계 본문 + AI 활용 기술서)은 공모전 제출 규정에 따라 이 공개 저장소에 올리지 않습니다.
