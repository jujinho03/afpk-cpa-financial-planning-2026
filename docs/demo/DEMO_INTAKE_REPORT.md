## 6. 금융 모형 정합성

**Rust 데모는 Python v4의 동일 수식 포트가 아닌 별도 가정의 확장 모형입니다.** 안전자금 고정 360, 임금 270/320/410, 첫 근로·급여 시점, D의 잔액 트리거, 할인 방식과 초기 현금 포함 여부가 다릅니다. 따라서 두 모형의 장기 지표를 같은 값으로 홍보하거나 한쪽 결과를 다른 쪽의 독립 검산 증거로 쓰지 않습니다.

[DEMO_BIBLE_GAP_ANALYSIS.md](DEMO_BIBLE_GAP_ANALYSIS.md)에 입력·단위·경로·수식·판정·증거 차이를 기록했습니다. 주진호가 단일 기준으로 통일할지 결정하기 전에는 두 기준을 명시해 공존시킵니다. ICL 보조 계산도 실제 통지·이자·기납부 등을 모두 반영한 확정 법정 의무가 아닙니다.

## 7. AI 증거와 번호 매핑

제공 원출력은 [cpa_experiment_runs.json](../../apps/demo/ai/evaluations/cpa_experiment_runs.json)의 8run·23claims입니다. 모델·시각·시스템 프롬프트·입력·원출력은 존재하지만, 이번 통합에서 과거 제공자 실행을 독립적으로 입증하거나 사람이 최종 판정한 것은 아닙니다. 상태는 **IMPORTED_UNREVIEWED**입니다.

바이블 E5(첫 지급일)·E6(공부시간/C 취업지연)와 데모 E5(지원금)·E6(장기 가치만 보고 중간 부족 무시)는 질문이 다릅니다. 같은 ID만으로 실험 완료를 합산하지 않습니다. [AI 증거 인덱스](../../ai_evidence/README.md)

## 9. 승인·배포 경계

현재 사용자의 요청은 기존 데모의 안전한 통합·검증·PR 병합입니다. 금융 가정·최종 권고 변경은 주진호 검토, AI 기술·제공 기록은 설경민 검토, 실행환경·코드는 박동찬 검토 대상으로 기록합니다. 이번 자동 검토와 CI를 독립 인간 승인이라고 표현하지 않습니다.

외부 배포·터널·유료 LLM 호출·음성 재생성·영상 렌더·최종 참가작 제작을 수행하지 않았습니다. 저장소 Public과 웹서비스 공개 운영은 다릅니다. 실제 개인정보·키·서명 서류를 업로드하지 않습니다.
