# 기존 데모 인수 보고서

기준일: 2026-11-12 KST
상태: `NOT_ASSESSED` — 설경민의 GitHub 원본 업로드와 실행 정보 대기

이 문서는 데모 소스 미제공 상태를 기록한 인수 준비 문서다. 구현된 기능이 없다는 판정이 아니며, 데모 인수·실행·GitHub 업로드 완료를 뜻하지 않는다. 사용자 지시에 따르면 설경민이 기존 데모를 제작했다. 작성자와 기능은 소스를 받은 뒤 확인한다.

## 2. 기술 스택과 폴더 구조

프런트엔드·백엔드·언어·패키지 관리자·데이터 저장소·외부 API·LLM·환경변수·인증 방식은 모두 `NOT_ASSESSED`다. 파일명이나 바이블의 목표로 기술 스택을 추정하지 않았다. 원본 폴더 구조도 아직 확인하지 못했다.

확인 후 `package.json`/lockfile, Python 환경 정의, 실행 진입점, API 경로, 저장소 연결, 인증 경계를 근거 파일 경로와 함께 기록한다. 기존 구조를 임의로 변경하지 않고, 모노레포에 넣는 경로와 원본 경로의 대응표를 추가한다.

## 4. 현재 확인한 문제

1. 사용자가 설경민의 추후 GitHub 업로드를 지정했으며, 현재 원본과 실행 정보는 아직 없어 데모의 인수·실행·정합성 검사가 진행되지 않았다.
2. 기존 v4 Python 모형과 PDF 생성기는 확보했지만, 이것이 설경민의 데모 소스라는 근거는 없다.
3. 바이블에 적힌 기능을 데모의 현재 기능으로 간주할 수 없다.

재무모형 자체의 알려진 제한은 모형 검산·변경 기록에서 관리한다. 이를 실제 데모 오류로 기록하지 않는다.

## 5. 설경민에게 받을 인수 패키지

- 원본 폴더의 정확한 경로, ZIP 또는 접근 가능한 GitHub 저장소 URL 중 하나
- 기존 Git 저장소가 있다면 URL·브랜치·인수 기준 커밋과 이력 보존 방식에 대한 의견
- 실행 환경, 패키지 관리자와 버전, 설치·개발·빌드·테스트 명령
- 필요한 환경변수의 **이름과 용도**; 실제 키·토큰은 채팅이나 Git에 전달하지 않음
- 실제 AI 호출 여부, 제공자·모델명, 서버/클라이언트 호출 위치, 모의 응답 여부
- 현재 정상 기능·알려진 오류·미완성 부분과 대표 확인 절차
- 금융 계산 위치, 단위, 고정 예시 데이터와 실제 계산 결과 구분
- 원저작자·외부 코드·폰트·이미지·에셋의 라이선스 정보

## 7. 변경과 승인 경계

계산 가정·권고 변경은 주진호, AI 연결·실험 변경은 설경민, 실행환경·통합 변경은 박동찬의 검토 대상으로 기록한다. 기존 데모 전면 재작성·기능 삭제·이력 재작성·프레임워크 이전·배포·유료 서비스·공개 전환은 이 초기 인수 작업에 포함하지 않는다. 원본 접근권한이나 보존 방법이 불분명하면 복사·이력 변경을 진행하지 않고 대안을 기록한다.

## 9. GitHub를 통한 원본 전달

설경민은 `feature/demo-import`에 원본을 올리고 작성자·원본 위치·기존 이력·실행 명령을 기록한다. `main`에는 직접 업로드하지 않는다. `.env`, 키·토큰, `node_modules`, 가상환경·빌드 캐시는 제외한다. 기존 Git 이력이 있다면 먼저 보존 방식을 협의하고 이력을 덮어쓰거나 강제 push하지 않는다. 소스가 실제로 올라온 뒤 인수 PR을 만들며, 박동찬이 설치·실행·빌드·테스트와 원본 기능을 확인한다. 주진호는 금융 수치 변경을, 설경민은 AI 관련 변경을 검토한다. 실제 업로드 전에는 PR·실행·기능 확인을 완료로 기록하지 않는다.
