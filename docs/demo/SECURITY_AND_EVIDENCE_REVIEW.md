## 점검 범위

- 원본 업로드의 변경 파일 243개, 약 9.0MB를 목록화했습니다. 단일 파일 최대 약 2.06MB이며 대형 모델·DB·빌드 결과는 발견하지 못했습니다.
- UTF-8 텍스트에서 GitHub 토큰·Google/OpenAI 키 형식·비밀키·이메일·한국 휴대전화·사용자 홈 경로 패턴을 검사했고 해당 패턴 일치는 0건이었습니다. 예제 토큰·빈 키 설정은 실제 비밀값과 구분했습니다.
- PNG 스크린샷 6개를 시각 확인했습니다. 일반 FINOVA 합성 고객 화면이며 PNG 메타데이터가 없습니다. 현재 CPA 화면의 새 실행 증거로 취급하지 않습니다.
- WAV 8개의 RIFF 부가정보는 FFmpeg 소프트웨어 태그였습니다. 실제 사람 녹음이나 음성 권리의 출처를 이번 검토로 새로 입증하지 않았습니다. 제공 문서는 Gemini TTS 생성 음성이라고 설명합니다.
- `.env`, 로컬 DB, `node_modules`, 가상환경, build/dist/out, 중첩 `.git`, 제출 PDF는 원본 업로드에서 제외됐고 관련 ignore 규칙을 확인했습니다.
- 이 점검은 완전한 보안·저작권 감사가 아닙니다. 외부 서비스를 호출하거나 키를 조회·출력하지 않았습니다.

## 확인한 방어와 남은 운영 제약

- 관리자 작업은 `x-admin-token`을 검사하고 운영 모드에서 미설정이면 비활성화합니다. 단, 알려진 개발 토큰을 운영 자격증명으로 쓰면 안 됩니다.
- SQL 쿼리는 바인딩 인자를 사용합니다. 테이블 이름은 코드의 고정 분기입니다.
- 주제 버전 ID는 허용된 문자·길이를 검사하며, 프리셋 로더는 고정 프리셋·고정 파일명을 읽습니다. AI 프롬프트 경로는 상위 디렉터리·절대 경로를 거부합니다.
- JSON 요청 크기는 512KiB로 제한되고, 여러 입력 타입이 `deny_unknown_fields`를 사용합니다. 이 사실만으로 전체 DoS 방어를 완료했다고 말하지 않습니다.
- Gemini 호출은 서버 측에 있고 프런트엔드 키를 발견하지 못했습니다. 모델 ID 허용 문자, 시간 제한, 실제 키 문자열 오류 마스킹이 있습니다. 쿼리 문자열 인증을 사용하므로 외부 프록시·상세 HTTP 로그 등까지 안전하다고 보장하지 않습니다.
- 생성된 주제는 허용된 구성·모듈을 조합하며 받은 코드를 서버에서 실행하지 않습니다. 입력 검증·스크립트 거부 테스트 코드가 있으나 테스트 성공 여부는 실행 기록으로 별도 확인해야 합니다.
- `localhost` 실행도 같은 기기의 다른 프로세스·브라우저 확장과 격리되는 것은 아닙니다. 실제 개인정보와 실자금을 넣지 않는 합성 데모 범위를 유지합니다.
