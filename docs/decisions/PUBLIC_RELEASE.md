# 공개 전환과 심사위원용 정리

기준일: 2026-11-12 KST.

## 승인과 범위

사용자가 기존 GitHub 저장소를 Public으로 전환하고 심사위원이 보기 좋은 프로젝트로 정리하도록 명시적으로 요청했습니다. 이는 초기 Private 유지 지시를 대체합니다. 웹서비스 배포·유료 전환·데모 재개발·금융 수치 변경·최종 참가작 제작은 포함하지 않습니다.

**대상:** https://github.com/jujinho03/afpk-cpa-financial-planning-2026

공개되면 저장소의 코드·문서·Git 이력과 Issue 등을 비로그인 방문자가 볼 수 있습니다. 팀 이름·GitHub 계정·가상 고객 자료가 포함된 연구·협업 저장소이며, 공모전 제출용 익명 본문과 구분합니다. 원본 바이블의 ‘내부 공유용’은 원본 작성 당시의 용도이며 후속 공개 승인은 이 문서에 기록합니다. 원본 해시는 유지합니다.

## 공개 전 점검

- 원격 다섯 브랜치를 확인했으며 현재 팀원 데모 업로드는 없습니다. 기존 코드를 덮어쓰거나 브랜치를 삭제하지 않았습니다.
- 초기 전체 이력 2커밋·고유 Git blob 50개·추적 파일 49개를 점검했습니다. 자격증명·개인 연락처·사용자 홈 경로·비밀값 할당 패턴에서 공개를 막을 문제는 발견하지 못했습니다.
- PDF 17쪽과 메타데이터를 확인했습니다. 첨부파일·주석은 없고, 외부 링크 4개는 공식 근거 URL입니다.
- 커밋 작성자 이메일은 GitHub noreply입니다. 고객명·금액은 가상 사례로 구분돼 있습니다.
- `.env`, 키, 서명 서류, 실제 개인정보, 가상환경·캐시·분석 임시파일은 공개 추적 대상에서 제외합니다. 신규 파일은 Git index 패턴 검사와 상대 링크 검사를 거칩니다.
- 위 점검은 제한된 정적 검사이며 모든 비밀정보·저작권·보안 문제 부재를 보증하지 않습니다. 기존 자료에 새 오픈소스 라이선스를 임의로 부여하지 않았습니다.

## 심사위원용 개선

| 개선 | 확인할 수 있는 내용 |
|---|---|
| 결과 중심 README | 고객 갈등 → 판단 순서 → 네 전략 → 반례 → 근거 |
| 3분 안내 | 수치·코드·원본·한계의 탐색 경로 |
| SVG 3개 | 18개월과 60개월의 구분, 안전자금과 미충당액의 차이 |
| 실제 CI 배지 | 워크플로 실행 결과로 연결 |
| 가정·미완료 상태 공개 | 외부 AI 실험 미실행, 데모 미평가, ICL 등 검증 필요 |
| 기여 안내 분리 | 기존 데모 인수·협업 절차는 유지하고 첫 화면은 독자 중심으로 정리 |

그림은 `outputs/tables/`를 읽어 생성하며 금융 계산·원본 바이블·기존 결과값은 변경하지 않습니다. 테스트 통과에는 알려진 결함의 재현 확인도 포함됩니다.
