## 02 왜 이 주제인가

CPA라는 낯선 소재를 금융문제로 바꾸는 핵심은 “합격 전·후 두 번의 소득 공백”이다.

- 고객은 아직 급여가 없지만 월세·생활비·학자금대출이 이미 존재한다.

- 마지막 응시 기회가 정해져 있어 선택을 무한정 미룰 수 없다.

- 최종 합격 이후에도 수습기관 확보와 실제 첫 급여 사이의 시간이 불확실하다.


### 용어는 두 문장만 알면 충분하다

| 용어 | 심사위원을 위한 설명 | 재무설계에서의 의미 |

|---|---|---|

| 유예생 | 전년도 제1차 합격 자격으로 다음 해 제2차시험에 응시하는 사람 | 마지막 응시권이 있는 기간의 생활비 확보 |

| 수습처 미지정 | 최종 합격 후 실무수습 기관을 아직 확보하지 못한 상태 | 첫 급여 시작 시점이 지연될 가능성 |

**26.3%** — 2026 전체 2차 합격률

**61.0%** — 2026 유예생 집단 합격률

**959명** — 2026 유예생 합격자

**공식 제도에서 확인되는 사실** — 금융위원회의 2026년 5월 수습 안정화 방안은 장기 미지정자(예: 합격 후 2년 이상)를 우선 대상으로 한 한시적 배정 지원을 제시했다. 모든 신규 합격자의 수습·고용·급여를 즉시 보장한다는 의미가 아니다. [S3]

### 단기 제약: 고객이 먼저 지켜야 하는 것

**현금흐름과 최초 위반월** — C(t) = C(t-1) + 근로·가족지원 등 확정된 현금유입 - 필수생활비 - 실제 채무지급 - 수험비.   τ = 최초로 C(t)가 시점별 Cmin(t)에 미달하는 월.

| 기간 | 최소 안전자금 Cmin(t) | 계산 가정 |

|---|---|---|

| 2026.12~2027.06 | 420만 원 | (생활비 120 + 수험비 20) × 3개월 |

### 장기 비교: 같은 조건으로 계산해야 의미가 있다

3가지 시험 결과 상태 P(합격·수습확보), U(합격·수습미확보), F(불합격)를 나눠 소득경로를 계산한다. p와 q는 각각 합격 및 수습확보의 미확인 조건변수이며, 개별 확률을 예측하지 않는다. 60개월 비교는 초기 가용현금을 포함한 할인 순현금흐름 지표이지 실제 순자산 예측치가 아니다.

## 06 18개월 현금흐름으로 확인한 위험

가상 고객 기준값에 대한 재현 계산. 음수는 현금이 아니라 미충당액이며 그래프는 0에서 자른다.

| 경로 | 안전자금 최초 위반 | 2028.05 시점 |

|---|---|---|

| A / 수습 미확보 스트레스 | 2027.10 | 현금 0 / 미충당액 555만 원 |

| B / 시간제 근로 | 위반 없음 | 가용현금 1,025만 원 (U 경로) |

| C / 취업 가정 | 위반 없음 | 가용현금 약 2,834만 원 |

| D / 정상 취업 | 위반 없음 | 가용현금 845만 원 (U 경로) |

| D / 취업 2개월 지연 | 2028.03 | 2028.05 가용현금 545만 원 / 중간 위반 |

**이 그래프가 말하는 것** — A는 18개월 말의 금액이 어떻든 2027.10에 먼저 지급능력 제약을 위반할 수 있다. B·C·D의 안전성은 시나리오상 첫 급여가 실제 발생한다는 조건부 결과다.


## 07 60개월 재무가치 비교의 최종 해석

예측값이 아닌 가정값 기반 모형 결과. 지표 순위와 고객의 응시권 선호는 별개다.

| 공통 입력 | 사용한 가정 | 주의 |

|---|---|---|

| 급여 | 일반직 실수령 230만/월, CPA 경로 실수령 290만/월 | 실제 취업 보수 조사 전의 합성값 |

| 성장·할인 | 일반직 연 3%, CPA 경로 연 5%, 할인율 연 5% | 임금 성장도 확정되지 않음 |

| 조건변수 | p=0.60, q=0.70, B의 Δp=10%p | 개인 확률·미지정률 추정치가 아님 |

| 학자금 | 2029.01부터 월 20만 자발적 상환 가정 | 법정 ICL 의무상환액과 구분 |

**기본 결론의 정확한 표현** — 가상 조건에서 C는 60개월 할인 순현금흐름 지표 약 6,717만 원으로 B 약 6,062만 원보다 655만 원 높다. 그러나 마지막 응시기회의 비금전적 가치는 이 지표에 포함되지 않았으므로, B는 “선택권 유지의 비용”을 설명한 후 고객과 합의해야 하는 대안이다.

**약 333만** — CPA 실수령 월 보수의 B/C 전환조건 예시

**2027.07** — C 첫 급여 3개월 지연 예시

현재 가정 p=0.60, q=0.70, Δp=10%p에서 CPA 경로의 첫 월 실수령을 약 333만 원 이상으로 설정하면 B가 C를 앞서는 경계가 나타난다. 반대로 C 첫 급여가 2027.04에서 07로 지연되면 C의 지표는 약 5,969만 원으로 낮아지는 조건부 예시가 나온다. 보수 경계와 일정 지연은 현실 자료로 검증된 예측이 아니다.


### 고객에게 숨기면 안 되는 불확실성

- B 시간제 근로가 실제 CPA 합격조건을 얼마나 낮추는지 측정한 데이터는 없다. 감소폭은 전적으로 민감도 분석 가정이다.

- 실제 CPA 수습 보수·일반직 취업 보수·첫 급여 월을 검증하지 않은 상태에서는 가치 순위가 쉽게 뒤집힐 수 있다.

- 18개월 안전성과 60개월 할인 현금흐름은 서로 다른 지표이므로 이를 혼합해 “가장 좋은 전략”이라고 단정하지 않는다.

**심사위원이 기대하는 해석** — 현재 가정에서 C가 재무가치 1위인 이유는 조기 급여 개시다. B를 선택하는 경우에는 마지막 유예기회와 금전적·시간적 비용을 고객에게 정량적으로 설명한다.


## 09 실제 고객에게 전달할 조건부 권고

고객의 재무목표와 선호가 확정되기 전까지 무조건적인 최적해를 선언하지 않는다.

**고객 설명문 초안** — “현재 가정에서는 즉시 취업 경로(C)가 장기 현금흐름에 유리합니다. 마지막 CPA 응시 기회를 반드시 보존하고 싶다면, 실제 구직·첫 급여일이 확인된 시간제 근로(B)를 병행하는 계획을 검토할 수 있습니다. 그 경우 공부시간 감소와 기본 비교에서 약 655만 원의 지표 차이를 함께 감수해야 합니다. 수습·취업 시점이 달라지면 계획을 바로 다시 계산하겠습니다.”


### 실행 전 반드시 확인할 네 가지 질문

| 질문 | 확인해야 하는 증거 | 재무계획에서의 처리 |

|---|---|---|

| 현금은 언제 들어오나? | 파트타임 계약·첫 급여일, 실제 구직 증빙 | 확정 전엔 현금유입으로 넣지 않음 |

| 학자금 의무는 언제 생기나? | 대출 유형·실제 통지·소득 귀속연도 | 월 20만 자발적 상환과 법정 의무상환 구분 |

| 가족 지원은 확정되었나? | 지원 조건·감액 날짜 확인 | 변경 시 현금흐름 재산정 |

| 응시기회를 유지할 가치는? | 고객이 감수할 최대 금전·시간적 손실 | B·C의 선택은 고객이 최종 결정 |


### 결과가 바뀌면 함께 바뀌는 행동

- 첫 급여가 늦어지면 단기 지급능력을 최우선으로 재계산한다.

- 수습처를 확보하지 못한 경우에도 대체 근로소득 가능성을 별도 확인한다.

- 기존 위험 가정이 틀리면 AI 출력과 함께 계산·권고의 버전을 남긴다.

## 11 AI가 추가해야 할 가치와 검증의 증거

AI가 더 멋진 문장을 쓰는 것보다 “놓친 조건”을 발견하고 권고를 바꾸는 과정이 중요하다.

| 역할 | AI가 하는 일 | 인간/코드가 검증할 것 |

|---|---|---|

| 정보 점검 | 고객 진술에서 빠진 첫 급여일, 가계지원 변경 등 탐색 | 가정 확정·현실성·개인정보 확인 |

| 시나리오 생성 | 실업·수습 지연·파트타임 지연 반례 제안 | 중복 제거, 조건변수 고정 |

| 코드·분석 초안 | 현금흐름 계산 코드 및 테스트 케이스 생성 | Python 독립 코드·손계산 교차검증 |

| 고객 커뮤니케이션 | 복잡한 수치를 행동문으로 번역 | 수치·법령·권고 적합성 최종 승인 |


### AI 검증 실험 E1~E6 (아직 실행 전)

| 실험 | 검증할 위험 | 독립 판정 기준 |

|---|---|---|

| E1 | 집단 합격률을 개인 확률로 사용 | CPA 유형별 분모와 조건부 가정 구분 |

| E2 | 합격 즉시 월급이 나온다고 처리 | 수습지원 대상·첫 급여 지연 모형 대조 |

| E3 | 부분합격 면제 적용연도 혼동 | 금융위 시험 시행계획 조항 |

| E4 | ICL을 매월 원리금 상환으로 간주 | 국세청 귀속연도·의무상환 통지 |

| E5 | 근로 시작일과 지급일을 동일시 | 구직·급여 지연 스트레스 테스트 |

| E6 | B 공부시간 손실·C 취업지연 무시 | Δp·채용월·급여 민감도 코드 |

**증거 패키지 4단계** — 모든 실험은 (1) 프롬프트·모델·시각 → (2) AI 원출력 → (3) 공식문서 또는 Python 검산 → (4) 수정 전후 고객 권고를 세트로 남긴다. 오류가 나오지 않으면 정확한 답변이라고 기록한다.

### 권장 저장소 최상위 구조 — 실행 LLM이 구체화

```text
docs/             # 공식 근거·가정 원장·보고서 초안
model/            # 현금흐름·장기 가치·시나리오 코드
tests/            # 결과 재현·경계조건 테스트
ai_evidence/      # 실험 기록 (민감정보·비밀키 제외)
output/           # 그래프·표·제출 전 검토용 산출물
README.md         # 사용법·재현 명령·상태·담당
requirements.txt  # 의존성 고정
```

**외부 작업의 경계** — 이 바이블 작성 과정에서는 GitHub 저장소나 외부 앱을 실제 생성하지 않았다. 후속 LLM은 연결 권한·기존 저장소 유무를 확인하고 중복 생성 없이 private 저장소부터 계획하며, 생성 성공을 확인하기 전 완료라고 쓰지 않는다.
