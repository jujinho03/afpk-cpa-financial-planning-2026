## 범위 잠금

1. 기존 8개 화면과 엔진을 새로 만들지 않습니다. 차이·결함이 있는 부분만 근거를 남겨 수정합니다.
2. 금융 수식·가정·고객 권고 변경은 영향 분석·검산·주진호 검토가 필요합니다. 이번 인수에서는 Python 결과와 Rust 원본의 역할을 보존합니다.
3. AI 1차 의견·자동 계산 판정·인간 최종 판단을 구분합니다. 인수한 원출력은 이번에 새로 실행한 실험이 아닙니다.
4. 강제 push·이력 재작성·기능 삭제·배포·유료 결제는 이 원장만으로 승인하지 않습니다. 저장소 Public 전환은 이미 사용자가 별도로 승인한 이전 작업입니다.
5. 기능별 최신 실행 상태는 인수 보고에서 관리하고, 문서에 과거 성공 수치를 복사해 현재 성공처럼 쓰지 않습니다.

## 계획 확정에 남은 의존성

소스 미확보 의존성은 해소됐습니다. 이제 가장 큰 의존성은 **로컬·CI 실행 결과, 두 금융 프로필의 보고서 처리 방식, AI 기록의 인간 판정, 공식 양식·본문/부록 진척**입니다. 문제가 생기면 P2를 제거하고 P0와 재현 가능한 최소 데모 범위를 먼저 완성합니다. 최종 3인·3일 실행 프롬프트 PDF는 이 입력을 확인하고 주진호의 다음 단계 지시 후 제작합니다.
