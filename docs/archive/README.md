# 보관 문서

이 폴더의 문서는 **작성 당시의 계획·설정 기록**입니다. 현재 결론이나 수치의 근거로 읽지 않습니다. 현재 기준은 [문서 지도](../README.md)를 따릅니다.

| 폴더 | 내용 | 보관 이유 |
|---|---|---|
| [`sprint/`](sprint/) | 데모 인수 전의 3일 일정 입력자료, 기능 목록, 개발 우선순위 | 작업 경위 추적. "데모 미평가" 같은 당시 상태가 남아 있음 |
| [`setup/`](setup/) | GitHub 저장소 초기 설정 인계, 초기 Issue 목록 | 저장소 구축 경위 추적 |
