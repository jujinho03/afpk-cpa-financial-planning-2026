상태: **소스 업로드 대기 / NOT_ASSESSED**. 이 파일은 웹앱 구현이 아닙니다.

설경민은 초대 수락 후 `feature/demo-import`에서 원본을 제공합니다. 원본 프로젝트 폴더명이 있다면 `apps/demo/<원본폴더명>/`에 그대로 두어도 됩니다. 기존 README·lockfile·라이선스·에셋을 보존합니다. 새 프레임워크로 옮기거나 금융 수치를 바이블 숫자로 하드코딩하지 않습니다.

함께 필요한 정보: 원본 저장소 URL/커밋(있다면), 작성자, 패키지 관리자·런타임 버전, 설치·실행·빌드·테스트 명령, 환경변수 이름(값 제외), AI 제공자·호출 위치, 금융 계산 위치, 고정 예시 데이터 구분, 알려진 오류, 라이선스.

`.env`, 실제 API 키·토큰, 개인정보, 서명 서류, `node_modules`, 가상환경, 빌드 산출물은 제외합니다. 기존 Git 이력이 있다면 임의로 없애거나 저장소를 중첩 복사하지 말고 보존 방식을 협의합니다.

실제 코드 반영 후 PR을 작성합니다. 박동찬이 로컬 실행·주요 기능·빌드를 확인하고 설경민이 AI 구현과 원본 보존을 검수합니다. 미실행 명령·기능을 완료로 쓰지 않습니다. 배포는 별도 요청 전 수행하지 않습니다.
