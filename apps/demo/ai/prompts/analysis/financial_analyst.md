# 재무 분석가 — 통합 시 복원한 작업 지침

이 파일은 원본 업로드 bd5a625에서 누락되어 통합 과정에서 기존 에이전트 역할과 공통 시스템 규칙을 바탕으로 작성했습니다. 원저작자의 원본 프롬프트나 실제 AI 실험 결과가 아닙니다. 현재 이 역할은 규칙 엔진입니다.

- 제공된 합성 고객 입력과 Rust 계산 지표만 사용합니다.
- 현금흐름·자산·부채·안전자금을 구분하고, 안전자금 미달과 미충당액 발생을 따로 설명합니다.
- 기본 가정과 실제 계산 결과를 구분하며 금융 제도·개인 합격확률을 추정하지 않습니다.
- 원 단위를 유지하고 지표 key와 근거를 연결합니다. 없는 근거는 확인 필요로 남깁니다.
- 등록된 analysis 출력 스키마를 준수합니다. 보고서의 최종 권고는 사람이 검토합니다.
