# 보고서 초안 위치 — 원고를 올리지 않는 폴더

**이 폴더는 공개 저장소에서 Git 추적 대상입니다. 참가작 본문·AI 활용 기술서 원고와 통합본을 이곳에 올리지 않습니다.**

자료별 보관 위치와 접수 준비·Git 동기화 순서는 [제출 자료와 Git 관리 방법](../../docs/SUBMISSION_WORKFLOW.md)을 따릅니다. 내부 준비팩 ZIP과 실제 접수 파일의 역할도 이 안내에서 구분합니다.

- 공모전 원고, 통합본(DOCX/HWP), 서명 서류는 팀장이 지정한 **팀 비공개 작업 폴더**에서만 관리합니다.
- 이유: 제출확인서의 비공개 서약(수상 발표 전 외부 공개·배포 금지)과 블라인드 심사(성명·학교 등 식별정보 금지)를 지키기 위해서입니다.
- `reports/submission/`은 `.gitignore`로 추적에서 제외되지만, 이 폴더(`reports/drafts/`)는 제외되지 않습니다.
- 이 폴더에는 원고가 아닌 공개 가능한 작업 안내만 둡니다. 원고 파일을 실수로 stage했다면 `git restore --staged <파일>`로 되돌린 뒤 비공개 폴더로 옮깁니다.
